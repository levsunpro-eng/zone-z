# Зона Z

Шутер от первого лица для Windows на карте заброшенного зоопарка «Последняя смена». Проект на Unity 6000.3.15f1 с URP: командный бой 12 на 12, Deathmatch, боты, оружие, способности, прокачка и мастерская скинов.

Карта использует вечернее освещение, текстуры с рельефом, мягкие тени и объёмную траву. Белки, крысы и черепаха свободно перемещаются по парку. Миникарта находится справа сверху: живые союзники отображаются всегда, противники — только в поле зрения без препятствий; при потере видимости метка исчезает.

## Сборка и запуск

1. Установите Unity Editor **6000.3.15f1** с модулем Windows Build Support и активируйте лицензию Unity.
2. Скачайте исходники целиком или клонируйте репозиторий. В Unity Hub добавьте папку `UnityProject` и дождитесь импорта зависимостей.
3. Закройте редактор перед пакетной сборкой. В PowerShell из корня проекта выполните:

```powershell
./tools/build-minimap.ps1 -Editor 'C:\Program Files\Unity\Hub\Editor\6000.3.15f1\Editor\Unity.exe'
```

Если редактор установлен в другой папке, укажите фактический путь. Сцену, материалы и настройки сборки подготавливает `ZoneZ.Editor.BuildTasks`; перед сборкой запускаются валидаторы проекта.

4. Запустите `ИГРАТЬ.cmd` или `Builds/Minimap/ZoneZ.exe`. Для передачи собранной игры нужна вся папка `Builds/Minimap`, включая `ZoneZ_Data`, `MonoBleedingEdge` и библиотеки.

Готовые исполняемые файлы, кэш Unity и локальные сохранения не хранятся в истории исходников. Скрипты запуска работают после сборки. Старые скрипты для отдельных редакций игры требуют соответствующих сборок.

## Управление

WASD — движение, мышь — обзор, ЛКМ — огонь, ПКМ — прицел, R — перезарядка, пробел — прыжок, Ctrl — присед, Shift — ходьба, E — подбор, Q — способность, 1–4 — оружие, Tab — счёт, Esc — меню.

## Проверки

После сборки:

```powershell
./tools/test-minimap.ps1 -Action Review
./tools/test-minimap.ps1 -Action Smoke
```

Тесты используют отдельные профили. Проверенная локальная редакция прошла 28 проверок миникарты и 255 игровых проверок. Описание методики и ограничений — [MINIMAP_REPORT.md](docs/MINIMAP_REPORT.md). Упоминаемые в исторических отчётах локальные журналы, изображения и папки `artifacts` не включены в репозиторий; новые результаты создаются при запуске тестов.

## Сеть

Есть прямое подключение, сервер лобби, приглашения и поиск соперников. Публичный сервер не предоставляется: его необходимо развернуть отдельно. Инструкции — [server/README.md](server/README.md) и [docs/ONLINE.md](docs/ONLINE.md).

Сервер написан на Python. Обычные серверные тесты: `python -m unittest test_lobby_server.py` из папки `server`. Для тестов смены TLS-сертификата сначала создайте локальные тестовые сертификаты по [инструкции](server/testdata/tls/README.txt); приватные ключи в репозиторий не включаются.

## Структура и материалы

- `UnityProject/Assets`, `Packages`, `ProjectSettings` — Unity-проект.
- `data` — игровые параметры; сборка копирует их в Unity Resources.
- `art-source` — исходные материалы моделей и сведения об их происхождении.
- `tools` — сборка, проверки и инструменты подготовки ресурсов.
- `server` — сервер лобби и его тесты.
- `docs` — спецификации и исторические отчёты разработки.

Сведения о сторонних моделях и их лицензиях сохранены рядом с исходниками и в [каталоге ресурсов](docs/ART_ASSETS.md). У отдельных сторонних моделей указана CC0; это не означает, что весь проект распространяется под CC0. Общая лицензия на собственный код и материалы проекта пока не назначена.

Подробная история разработки: [README-DEVELOPMENT.md](README-DEVELOPMENT.md).
