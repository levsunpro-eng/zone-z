# Готовый вариант размещения на Fly.io

Конфигурация подготовлена, облачные ресурсы ещё не созданы. Для первого общего сервера друзей подходит одна Fly Machine во Франкфурте: отдельный VPS, свой домен и ручное обслуживание сертификата не требуются. Приложение получает адрес `ВЫБРАННОЕ-ИМЯ.fly.dev`. Публичный TLS принимает Fly Proxy, затем передаёт обычный TCP на внутренний порт 7780. Это собственный игровой протокол, поэтому в `fly.toml` указан только обработчик `tls`, без `http`. [Домены Fly](https://docs.fly.io/networking/custom-domain), [обработчик TLS](https://docs.fly.io/networking/services#tls-handler).

## Стоимость, проверено 10 октября 2026

После изменения цен с 1 октября ориентир для одной постоянно включённой машины `shared-cpu-1x`, 512 MB, регион `fra` — **около $4,26 за 30 дней**, плюс исходящий трафик и применимые налоги. Это расчёт: текущая базовая цена 512 MB — $3,69, коэффициент Франкфурта в официальном калькуляторе — примерно 1,153846. Старый ориентир $3,32 больше не актуален. Фактическая сумма зависит от длительности месяца и актуальной цены при создании ресурса. [Официальные цены](https://docs.fly.io/about/pricing), [региональный калькулятор](https://fly.io/pricing/), [изменение с 1 октября](https://fly.io/pricing-update/).

Исходящий интернет-трафик из Европы стоит $0,02/GB. Например, 100 GB добавят около $2; это пример расхода, а не включённый пакет или предел счёта. Через сервис идёт и игровой трафик, поэтому стоимость зависит от числа игроков и времени матчей. Постоянного бесплатного тарифа для новых организаций нет; пробный период ограничен. [Тарифы трафика и пробный период](https://docs.fly.io/about/pricing).

**Платный выделенный IPv4 за $2/месяц здесь не нужен.** Бесплатный shared IPv4 работает с нашим TCP, поскольку Fly Proxy завершает TLS и выбирает приложение по доменному имени. Для `.fly.dev` не нужно покупать собственный домен или загружать свой сертификат. [Shared IPv4 и TLS](https://docs.fly.io/networking/services).

Для небольшого круга друзей этот вариант прост в запуске и имеет небольшую базовую стоимость. Если важнее фиксированная сумма с большим включённым трафиком, имеет смысл отдельно сравнить VPS с включённым трафиком; у Fly итоговая цена зависит от использования.

## Что делает конфигурация

- Один процесс в регионе `fra`, 1 shared CPU, 512 MB RAM.
- Внешний порт 443: TLS 1.2/1.3; внутренний 7780: TCP.
- Автоматическое выключение и запуск по запросу отключены, перезапуск процесса включён.
- Начальный предел 64 одновременных соединения, включая игроков в лобби и матчах. Это ограничение допуска, а не подтверждённая нагрузочным тестом производительность.
- Без БД, дисков, дополнительных регионов и резервной игровой машины.

Комнаты и очередь находятся в памяти одного процесса. **Машина должна быть ровно одна.** Второй экземпляр разделит игроков между независимыми очередями, и код друга может оказаться неизвестен. Поэтому при каждом деплое нужен `--ha=false`; при необходимости число экземпляров проверяется `fly scale show`. Перезапуск или обновление сервера прерывает текущие матчи и удаляет комнаты. [Резервные машины при deploy](https://docs.fly.io/flyctl/cmd/fly_deploy), [управление количеством машин](https://docs.fly.io/launch/scale-count).

## Развёртывание после выбора аккаунта и бюджета

Нужны собственный аккаунт Fly.io и вход в официальный `flyctl`. В этой подготовке CLI не устанавливался, аккаунт не создавался и платные операции не запускались. Следующие команды создают реальные облачные ресурсы и относятся к отдельному шагу развёртывания.

Из каталога `server` замените `YOUR_UNIQUE_APP` на свободное имя приложения:

```powershell
fly auth login
fly apps create YOUR_UNIQUE_APP
fly ips allocate-v4 --shared --app YOUR_UNIQUE_APP
fly deploy --config fly.toml --app YOUR_UNIQUE_APP --ha=false
fly scale count 1 --app YOUR_UNIQUE_APP
fly scale show --app YOUR_UNIQUE_APP
fly ips list --app YOUR_UNIQUE_APP
fly status --app YOUR_UNIQUE_APP
fly logs --app YOUR_UNIQUE_APP
```

`app` намеренно не записан в шаблон: явный `--app` исключает случайное использование чужого имени из примера. Бесплатный shared IPv4 выделяется явно: для сервиса без HTTP автоматическое выделение может не произойти. Перед публикацией проверьте, что работает ровно одна машина во Франкфурте с 512 MB, а в списке IP нет ненужного выделенного IPv4. Для обновления используется та же команда `fly deploy ... --ha=false`.

В игре у всех участников в поле «Адрес службы лобби» укажите `tls://YOUR_UNIQUE_APP.fly.dev:443`. Эту же строку можно записать в `online-server.txt` рядом с `ZoneZ.exe`, чтобы адрес уже был заполнен у друзей. Указывать IP вместо имени нельзя: нужны имя для маршрутизации и проверка сертификата. Браузер здесь не подходит для проверки, поскольку сервис не HTTP. Рабочая проверка — два клиента игры: один создаёт лобби, второй входит по коду; после создания второго независимого лобби оба лидера запускают поиск и получают один матч.

После реального размещения нужно проверить TLS из игры, вход двух друзей из разных сетей, общий поиск и расход трафика. До такой проверки этот файл подтверждает только готовность конфигурации, а не доступность публичного сервиса.
