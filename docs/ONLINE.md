# Как играть с друзьями

В меню «Играть» доступны локальная игра с ботами, лобби с приглашениями и поиском соперников, а также прямое подключение по адресу. Передайте друзьям одну и ту же сборку целиком: архив `Builds/ZoneZ-0.2.0-online.zip` содержит `ZoneZ.exe`, `ZoneZ_Data` и библиотеки, которые должны оставаться рядом.

**Публичная служба лобби пока не настроена и не развёрнута.** Пустое поле адреса в игре означает, что сначала нужен общий доступный сервер. Адрес из примера ниже — шаблон, а не работающий сервис. Совместная игра между разными домами через публичный интернет пока не подтверждена отдельной проверкой; локальный тест не заменяет такую проверку.

## Лобби, приглашения и поиск людей

1. Откройте «Играть → Онлайн · с друзьями → Лобби и поиск».
2. Введите ник и адрес вашей службы лобби, например `tls://game.example:7780`, заменив `game.example` настоящим именем настроенного сервера. Нажмите «Подключиться к службе». Все друзья используют один адрес.
3. Выберите командный бой или Deathmatch и нажмите «Создать лобби».
4. Нажмите «Приглашение»: в буфер попадут адрес службы и код лобби. Отправьте их друзьям. Можно отдельно скопировать код кнопкой «Копировать код».
5. Друзья подключаются к той же службе и выбирают «Войти по коду». Их имена появляются в списке; лидер помечен ромбом.
6. Когда все собрались, лидер нажимает «Найти соперников». Служба объединяет две группы одного режима и версии. В командном бою друзья из одного лобби остаются в одном отряде; в Deathmatch каждый играет за себя.

Поиск не добавляет ботов вместо отсутствующих соперников. Если другой группы на этой службе нет, поиск продолжится. Лидер может нажать «Отменить поиск соперников». Чтобы новый друг вошёл по коду, сначала отмените поиск. Выход участника также отменяет поиск группы; при выходе лидера его место занимает следующий оставшийся участник.

Командное лобби вмещает до 12 человек, лобби Deathmatch — до 20. Для поиска Deathmatch оставьте хотя бы одно место сопернику. Число людей в найденном матче зависит от размеров двух групп; полный состав 12 × 12 для запуска не требуется. Автоматической оценки навыка и рейтинга пока нет.

Матч начинается с подготовки. Адреса компьютеров друзей и проброс портов на их роутерах для этого варианта не нужны: сообщения проходят через общую службу. Один участник становится игровым хостом и считает бой на своём компьютере. Если он выйдет или потеряет связь, матч закончится для остальных. Переноса роли хоста нет.

Присоединение новых игроков в уже найденный матч через службу пока не поддерживается. После боя вернитесь в меню, создайте новое лобби и пригласите друзей заново.

## Отдельная игра с ботами

Для одиночной игры выберите «Играть → Локально · с ботами», затем режим. Служба лобби и интернет не нужны.

Чтобы тренироваться вместе с друзьями, соберите лобби и нажмите «Отдельный матч с ботами». Эта кнопка доступна лидеру при остановленном поиске. Свободные места займут боты. Запуск не выдаётся за найденный матч с людьми.

## Прямое подключение по адресу

Этот способ не использует службу лобби и не ищет соперников автоматически. Игроки присоединяются к компьютеру создателя; свободные места занимают боты.

1. Создатель открывает «Играть → Онлайн · с друзьями → По адресу → Создать матч».
2. Вводит ник, TCP-порт — по умолчанию `7777` — и код комнаты, выбирает режим и нажимает «Запустить сервер и войти».
3. Передаёт друзьям адрес своего компьютера, порт и код. Адрес и код можно скопировать через меню `Esc`. Если сетевых адаптеров несколько, кнопка смены IP позволяет выбрать нужный адрес.
4. Друзья выбирают «По адресу → Подключиться», вводят ник, адрес, отдельное значение порта и код, затем нажимают «Войти в матч».

В одной Wi-Fi/LAN-сети используйте локальный IP создателя. Для разных домов нужен доступный публичный IPv4 и перенаправление выбранного TCP-порта на компьютер создателя либо общая VPN-сеть с доступом между участниками. Укажите VPN-адрес, если играете через VPN. Разрешите входящие подключения игры в брандмауэре компьютера создателя. Адрес `127.0.0.1` подходит только для нескольких экземпляров игры на одном компьютере.

Локальный IP из меню не является публичным адресом. Если провайдер не предоставляет входящие подключения к вашему IPv4, обычного правила на домашнем роутере недостаточно: используйте общую VPN-сеть или вариант со службой лобби. Код комнаты служит паролем; он не заменяет IP и порт и не находит сервер самостоятельно.

В прямом режиме друзья могут входить в начавшийся матч, занимая места ботов. Закрытие игры создателем отключит всех. «Локально» или «Назад» отменяет ещё не завершённое подключение.

## Общие правила сетевого боя

- Выберите оружие и ульту в главном меню до подключения. Во время сетевой подготовки и ожидания возрождения смена снаряжения недоступна.
- `Esc` открывает меню, но не останавливает бой. Ваш персонаж остаётся на карте. В меню видны состояние соединения и количество людей.
- Прокачка здоровья, скорости и урона в сетевом матче отключена. За сетевые матчи кредиты не начисляются; локальная игра сохраняет свои правила наград.
- Хост перед выходом получает предупреждение о закрытии матча для всех. Обычный участник может отключиться, остальные продолжат игру.
- При несовпадении версии используйте одну и ту же сборку. При ошибке соединения проверьте адрес, порт и код, затем повторите подключение. В лобби для приглашения нужен код лобби; в прямом режиме — код комнаты создателя.

## Как запустить службу

Инструкция для администратора, TLS, порт, ограничения и протокол описаны в [server/README.md](../server/README.md).

Для бесплатного размещения выбран [Oracle Always Free](ORACLE.md). После регистрации аккаунта установщик выпускает доверенный сертификат на публичный IP VM; адрес в игре будет `tls://PUBLIC_IP:7780`. Этот шаблон не является адресом работающего сервера.

Для локальной проверки на одном компьютере запустите из корня проекта:

```powershell
python server/lobby_server.py
```

В игре введите `tcp://127.0.0.1:7780`. Для проверки автоматического поиска создайте два разных лобби и включите поиск в обоих. Вход двух игроков в одно лобби сам по себе не создаёт группу соперников.

Для игры из разных домов опубликуйте службу по инструкции сервера и передайте друзьям её настоящий адрес с `tls://`. Служба не появляется автоматически при нажатии «Создать лобби».

После настройки хостинга можно положить файл `online-server.txt` рядом с `ZoneZ.exe`. Запишите в него одну строку с настоящим адресом службы вида `tls://game.example:7780`, подставив свой домен. При следующем запуске этот адрес появится в поле лобби автоматически; подключение выполняется кнопкой игрока. Файл не содержит паролей и сам по себе не развёртывает сервер.
