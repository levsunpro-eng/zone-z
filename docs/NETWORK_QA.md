# Сетевая версия 0.2.0 — проверки 10 октября 2026

Windows x64, Unity 6000.3.15f1. Запуск: `ИГРАТЬ ПО СЕТИ.cmd`; самостоятельная поставка — `Builds/Online`. Обе прежние игры с ботами сохранены. Совместимость проверяется версией протокола и SHA256 канонического каталога баланса. Публичная служба пока не размещена.

## Реализованное поведение

- Прямой хост TCP 7777 (порт меняется), код комнаты, вход в текущий матч вместо бота, возврат бота после отключения.
- Через отдельную службу: приглашения в лобби, лидер группы, отмена поиска, поиск второй группы того же режима и версии. Друзья из одной группы сохраняют команду. Автоматический поиск запускает фактический состав людей без ботов; полный состав 12×12 не требуется.
- Отдельный запуск группы с ботами. Локальные боты также доступны без сервера и интернета.
- Клиент посылает управление; движение, патроны, попадания, урон, способности, предметы, смерти, возрождения, раунды и результаты рассчитывает игровой хост. Снимки 15 Гц, команды до 30 Гц. Камера реагирует локально; позиция приходит с сервера, без предсказания и компенсации задержки.
- Esc в сети не останавливает симуляцию. Постоянная прокачка в сети отключена, локальные кредиты за сетевой матч не выдаются.
- Ограниченные очереди, ограничения размера/частоты сообщений, таймауты, проверка версии и кода. TLS в соединении со службой проверяет доверие сертификата и имя сервера.

Игровые проверки подтверждают прохождение команд движения и стрельбы до сервера и обратно, урон и расход патронов на двух клиентах, смерть/возрождение, продолжение симуляции при открытом меню хоста, отключение игрока, закрытие хоста, отказ неверному коду и версии. Проверка лобби подтверждает приглашение, ожидание настоящего соперника, одинаковый состав/команды на трёх клиентах, движение через relay и последующий отдельный матч с ботами.

Первый тест лобби обнаружил сериализацию `searching=false` при нажатии поиска. Команда исправлена на `true`; оба режима повторно прошли полный сценарий. Ошибка тестового ожидания заставки в batchmode также исправлена до успешных прогонов. Проверки используют отдельные временные профили и не меняют сохранения игрока.

## Границы проверки

- Игровые соединения проверены через loopback одного компьютера. Внешний интернет, домашние NAT, задержки, потери и пропускная способность реального провайдера не проверены.
- Служба поддерживает TLS и готова к размещению; успешный публичный TLS-сеанс из Unity ещё не подтверждён. Тесты транспорта в PowerShell/.NET подтверждают отказ недоверенному сертификату и открытому тексту вместо TLS, таймаут зависшего рукопожатия за 8 секунд и немедленную отмену без перехода на открытый TCP. Эти проверки не подменяют проверку доверенного TLS-соединения из Unity с размещённым сервером.
- Графическая проверка скрытого окна не прошла проверку непустых пикселей: захват 1600×900 вернул однотонный кадр. Это не засчитано как визуальная приёмка новых меню. Интерфейс проверен по коду; окончательный просмотр в видимом окне остаётся отдельной проверкой.

- Нет аккаунтов, рейтинга, античита, миграции хоста и переподключения в уже найденный матч. Закрытие хоста завершает матч. Служба держит комнаты в памяти одного процесса; её перезапуск сбрасывает комнаты.
- Нагрузочная ёмкость 24 реальных игровых клиентов и 64 клиентов Fly-конфигурации не измерялась. Числа в конфигурации — ограничения допуска, а не результат нагрузочного теста.

## Воспроизведение

Для Oracle подготовлены [инструкция](ORACLE.md) и установщик `server/oracle/`. Аккаунта и размещённой VM ещё нет. Обновление TLS проверено на Python 3.9/Windows с временным доверием тестовым сертификатам только внутри SSLContext; Linux SIGHUP, реальный сертификат Let's Encrypt и выполнение установщика на Ubuntu требуют проверки на созданной VM.

Прогон Windows-игры через реальный сервер: `tools/test-lobby-game.ps1 -Executable Builds/Online/ZoneZ.exe -ServerEndpoint 'tls://PUBLIC_IP:7780'`. Внешний режим не запускает Python и не останавливает сервер. Сейчас подтверждены синтаксис и обработка URI; публичного прогона ещё нет.

Для явного запуска визуальной проверки пользователем: `tools/test-network-ui.ps1 -Visible`. Эта команда на время открывает тестовое окно игры, сохраняет пять кадров и затем закрывает только свой процесс. Скрытый запуск остаётся поведением по умолчанию.

```powershell
tools/build-online.ps1
tools/test-network-game.ps1 -Executable Builds/Online/ZoneZ.exe
tools/test-lobby-game.ps1 -Executable Builds/Online/ZoneZ.exe
tools/validate-transport.ps1
python -m unittest discover -s server -p "test_*.py" -v
tools/package-online.ps1
```
