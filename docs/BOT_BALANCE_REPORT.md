# Сложность ботов — 10 октября 2026 года

Баланс **1.0.1**. Проверенная Windows-сборка: [Builds/BotBalance/ZoneZ.exe](../Builds/BotBalance/ZoneZ.exe). [ИГРАТЬ.cmd](../ИГРАТЬ.cmd) переключён на неё; стандартные команды сборки и игровых проверок используют эту же папку. Предыдущая `Builds/Windows` сохранена, поскольку на момент обновления из неё работали два экземпляра игры.

## Изменения

Параметры находятся в [data/modes.json](../data/modes.json), блок `botDifficulty`:

| Параметр | Новое значение |
|---|---|
| Реакция на появление или смену цели | 0,65–1,05 с вместо 0,3–0,42 с |
| Обновление наблюдаемого положения цели | Раз в 0,24–0,36 с вместо каждого физического шага |
| Поворот к цели | До 115°/с вместо 190°/с |
| Ошибка прицеливания | Независимые плавные отклонения по горизонтали и вертикали; базовые пределы 2,8° и 1,8° |
| Стрельба | 2–4 принятых нажатия на спуск, затем пауза 0,55–1 с |
| Рассчитываемый урон бота | ×0,6, то есть на 40% меньше |

Проверка прямой видимости сохраняется перед стрельбой. Нативные очереди Glock/FAMAS и взвод R8 завершаются без отмены из-за паузы AI; нож и Zeus не используют ограничения очередей. Снижение урона применяется однократно при разрешении атаки, перед щитами и бронёй, включая обычный урон способностей. Механика мгновенного убийства «Абсолютного выстрела» остаётся отдельной.

У локального и удалённого игрока нет штрафа к урону. Оставшийся после смены сетевой роли компонент бота не превращает игрока в AI. Канонические характеристики оружия, прокачка и профиль не изменены. Все шесть таблиц согласованы по `balanceVersion: 1.0.1`; исходные JSON синхронизированы в Resources при сборке.

## Проверки

- [Build log](../artifacts/bot-balance-2026-10-10/build.log): `ZONEZ_BUILD_RESULT Succeeded`, `ZONEZ_VALIDATION_OK`. Пройдены Core, Profile (102 проверки), Combat (включая все 34 огнестрельных оружия), World и BotDifficultyValidation.
- Новый валидатор проверяет урон AI и игроков, щиты, броню, очередь урона без повторного множителя, фактически снятое здоровье для истории и вампиризма, сетевые роли, реакцию, интервалы наблюдений, паузы и сбросы очередей. Ошибка прицеливания проверена настоящими лучами по грудной зоне на 25 м. Некорректные настройки отвергаются.
- `tools/validate-data.ps1` прошёл с временной папкой внутри `artifacts/bot-balance-2026-10-10/validation-temp`.
- [Windows Smoke](../artifacts/bot-balance-2026-10-10/smoke/runtime-smoke.json): **255 проверок**, `passed=true`, `errors=[]`.
- [Soak](../artifacts/bot-balance-2026-10-10/soak/soak.json): оба полных матча завершены, `passed=true`, `errors=[]`. Командный бой — 2 раунда, 33 убийства, 44,58 реальной секунды; Deathmatch — полные 600 игровых секунд, 655 убийств, 153,74 реальной секунды. Симуляция ускорена ×4, игровой шаг остаётся 1/60 с. Убийства и результат не форсировались. Это проверка работоспособности ботов и завершения матчей; она не измеряет сложность против живого игрока.

Успешные игровые прогоны использовали отдельные тестовые профили. Новый замер FPS для этой редакции не проводился.
